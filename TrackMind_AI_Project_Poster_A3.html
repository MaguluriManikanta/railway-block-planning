❌ Uncoordinated Stoppages

Track, Signals, and OHE request isolated blocks on the same section, causing 3 separate shutdowns totaling 8+ hours of daily downtime.

⚠️ Data Silos & Friction

Absence of a real-time unified database linking TMS, SMMS, and TDMS with live timetables and freight forecasts causes friction.

⌛ Intractable Manual Math

Balancing overdue safety defect SLAs, track machine availability, crew roster limits, and zero train delay is manually intractable.

📌 Scope & API Limits

Requires standardized digital API feeds from legacy software (BDMS/COA/TMS). Prototype uses SQLite; production scales to Turso / PostgreSQL.

🛡️ SLA Governance: Monitored by 13 Autonomous Governance Agents with 3 Auto-Approval Risk Tiers.
1. Joint Shadow Block Clustering
Bundles Track, Signal & OHE into 1 shared outage—saving 4+ hrs daily!
2. Google OR-Tools CP-SAT Solver
Math constraint optimization for 7-day & 30-day zero-collision schedules.
3. Hybrid ML (Random Forest + Isolation)
Predicts breakdown risk P(f) & detects duration anomalies across 40 sections.
4. Dynamic Math Priority Scoring
Formula = 40% Severity + 25% Overdue + 20% Train Impact + 15% ML Risk.
5. 13 Autonomous Governance Agents
Coordinates SLA compliance, cost optimization, crew rosters & advisories.
6. 3-Tier Risk Auto-Approval Engine
Tier 1 Auto-Approve, Tier 2 Auto+Log, Tier 3 Critical Escalation.
7. Live Gantt & Plotly Timeline UI
Real-time zoomable corridor timeline visualization with live status logs.
8. Multilingual Voice AI (Groq LLM)
Llama-3.3-70B Web Speech API for voice in English, Hindi & Telugu.
